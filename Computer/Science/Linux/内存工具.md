# Memwatch

- 源码：https://gitee.com/wangdou2014/memwatch

## 介绍

​        可以检测的内存错误类型和功能

- 上下溢出
- 野指针
- 重复释放
- 内存限制
- 内存修复
- ...

### 原理

​        使用宏定义接替malloc等函数（memwatch.h）

```c
#define malloc(n)       mwMalloc(n,__FILE__,__LINE__)
#define strdup(p)       mwStrdup(p,__FILE__,__LINE__)
#define realloc(p,n)    mwRealloc(p,n,__FILE__,__LINE__)
#define calloc(n,m)     mwCalloc(n,m,__FILE__,__LINE__)
#define free(p)         mwFree(p,__FILE__,__LINE__)
#define CHECK()         mwTest(__FILE__,__LINE__,MW_TEST_ALL)
#define CHECK_THIS(n)   mwTest(__FILE__,__LINE__,n)
#define CHECK_BUFFER(b) mwTestBuffer(__FILE__,__LINE__,b)
#define MARK(p)         mwMark(p,#p,__FILE__,__LINE__)
#define UNMARK(p)       mwUnmark(p,__FILE__,__LINE__)
```

### 特点

- 简单、轻便
- 无法打印调用栈

## 部署步骤

1. 修改日志存放路径（mwInit函数）：设备上基本只能在`/tmp`或`/var`中写入日志

   ```c
   void mwInit( void ) {
       ...
       if( mwLogR() == NULL ) mwLogFile( "/var/log/memwatch.log" );
       ...
   }
   ```

2. 接管段错误信号，提前接收日志后再退出（新增逻辑）

   ```c
   void mwSegfaultHandles(int n)
   {
       mwAbort();
       signal(SIGSEGV, SIG_DFL);
   }
   ```

   ```c
   void mwInit( void ) {
   	...
       
       if( mwUseAtexit ) (void) atexit( mwAbort );
       signal(SIGSEGV, mwSegfaultHandles);
       return;
   }
   ```

3. makefile中编译时加入memwatch.c，将头文件放入路径中。配置编译选项（具体工程可以根据自己的加）

   ```makefile
   $(CC) -DMEMWATCH -DMW_STDIO test.c memwatch.c
   ```

   - 加源文件
   - 配置环境变量

4. 在源代码中加入

   ```c
   #include "memwatch.h"
   ```

   注意，如果源代码中包含了string.h，则memwatch.h应放到string.h后面。

## 函数功能说明

```c
CHECK();						// 主动打印，如一些进程是while循环运行的，可以每次运行主动check。
mwStatistics( 2 );				// 跟踪等级（定位到代码行）
mwLimit(1000000);				// 设置内存限制
mwNoMansLand( MW_NML_ALL );	
mwFlushNow();					// 主动刷新日志，特别在循环CHECK时，避免硬要缓存满了再刷日志
```

## 使用建议

- 源码多那工程量就大，所以越早加入越好，可以规定必须包含一个公共头文件。
- memwatch无法打印多级调用栈：不要弄libc的二次封装，尽量在顶层分内存。
